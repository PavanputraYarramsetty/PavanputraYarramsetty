### 🍽️ FoodNest (Aparnadevi Canteen)

A full-stack hostel canteen platform built for **Aditya University**. Students browse a live menu, place orders, receive digital tokens, and track order status in real time. Admins manage the menu, bill walk-in customers through a POS counter, view revenue analytics, and export Excel reports.
